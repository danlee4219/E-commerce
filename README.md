# ShopEase - Modern E-Commerce Website

A fully responsive and interactive E-Commerce Website built using HTML, CSS, and JavaScript with real product data fetched from the FakeStore API.

This project includes modern shopping features like authentication, cart management, wishlist system, product search, voice search, category filtering, checkout flow, and user-wise order management using LocalStorage.

---

# Features

## User Authentication
- User Registration
- Login & Logout System
- User-wise data handling
- Persistent login using LocalStorage

---

## Product Features
- Fetch products from FakeStore API
- Featured Products section
- Recommended Products section
- All Products page
- Dynamic Product Cards
- Product Ratings & Reviews

---

## Smart Search System
- Real-time search
- Keyword matching
- Category-based filtering
- Voice Search using Speech Recognition API

---

## Shopping Features
- Add to Cart
- Add to Wishlist
- Remove from Cart/Wishlist
- Duplicate item protection
- User-wise Cart & Wishlist

---

## Checkout & Orders
- Checkout Page
- Order Summary
- Form Validation
- Place Order functionality
- User-wise Order History
- Latest Orders displayed first

---

## Responsive UI
- Mobile Responsive Navbar
- Hamburger Menu Toggle
- Responsive Product Grid
- Modern UI Design

---
